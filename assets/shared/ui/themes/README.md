# vMenu's own themes

These four stylesheets are the looks vMenu ships with. 
`default.css`, `dark.css` and `cartoon.css` are here, and the plain Grand Theft Auto look needs no file at all. 
The server owner picks one with the `vMenu.Enhanced.MenuAppearance.Skin` setting.

**Please do not add your own theme to this folder.** 
A vMenu update overwrites everything in here, so your work would quietly disappear the next time you update. 
It also means you cannot share your theme with anybody without shipping a modified vMenu.

## Adding your own theme instead

Use the [vMenu Custom Themes plugin](https://github.com/TomGrobbe/vMenu.CustomThemesPlugin). 
It is a small resource of its own where you drop your stylesheet in a folder, name it in a JSON file, and restart it. 
vMenu then offers your theme next to its own ones, and it survives every vMenu update because none of it lives in vMenu.

Its readme walks you through the installation, and the theme it comes with is meant to be copied as a starting point.

If you would rather have your players pick their own look rather than picking one for everybody, the [Theme Picker plugin](https://github.com/TomGrobbe/vMenu.ThemePicker) adds a menu for that, and it lists themes from the custom themes plugin too.
