## Some clothing or upgrade numbers are skipped

:::note[FiveM Legacy]
This only happens on FiveM Legacy.
:::

Some clothing and vehicle upgrades only exist in the newer version of GTA V, the one FiveM Enhanced runs on. FiveM Legacy still counts them, but the game cannot use them, so vMenu skips them.

| Where | What you see |
| --- | --- |
| Clothing rows | The numbers jump. With 5 items where 2 and 4 are skipped, scrolling goes 1/5, 3/5, 5/5. The numbers stay the real item ids. |
| Jump To A Number | Typing a skipped number shows an error and nothing changes. |
| Saved outfits and saved peds | The skipped items are left out, and a notification or the restore message says so. |
| Vehicle upgrades and rims | Skipped upgrades are left out of the list, and the counter only counts the ones you can fit. |
| Saved vehicles | The vehicle spawns without the skipped upgrades. |
