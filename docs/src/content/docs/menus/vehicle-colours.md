---
title: "Vehicle Colours"
description: "How the Colours section of Vehicle Options works, and which paints it offers."
---

The Colours section of Vehicle Options works the same way as the respray menu in Los Santos Customs and the other mod shops in GTA Online.

- **Previewing.** Scrolling over a colour paints your vehicle with it straight away, but only as a preview.
- **Applying.** Pressing enter keeps the colour.
- **Backing out.** Leaving the list without pressing enter puts back the colour you had before.
- **The icon.** A car icon (a bike icon on bikes) marks the colour your vehicle has right now, and the list opens on that colour.

You have to be the driver of the vehicle to use this section.

## What is in the section

| Option | What it paints |
| --- | --- |
| Primary Colour | The main body colour. Opens a list of paint types. |
| Secondary Colour | The second body colour. Opens the same paint types, without Pearlescent. |
| Interior Colour | The trim inside the cabin. |
| Dashboard Colour | The dials and the dashboard. |
| Wheel Colour | The rims. |
| Factory Colour Combination | The colour pairs the vehicle ships with. Only shown when the vehicle has any. |
| Paint Fade | How sun bleached the paint looks. |

## Paint types

These are listed in the same order as in the mod shop. The colours in each type come from the game itself, so they always match what your game version has.

| Paint type | Notes |
| --- | --- |
| Chrome | |
| Classic | |
| Matte | |
| Metallic | Picking a metallic colour also sets a matching pearlescent, like in the mod shop. |
| Metals | Brushed steel, aluminium and gold. |
| Pearlescent | Primary colour only. Changes only the shimmer, not the colour itself. Works with any primary colour. |
| Chameleon | Paints that change colour depending on the angle you look at them from. Only shown when your game version has them. |
| Utility | Not in the mod shop. |
| Worn | Not in the mod shop. |
| Custom Colour | Not in the mod shop. Mix your own colour, or type a hex code. |
