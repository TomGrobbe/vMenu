---
title: "Vehicle Mines"
description: "Which vehicles can drop mines, which mine you get, and how to drop them."
---

Some GTA Online vehicles can be fitted with mines, but the game needs a script to actually drop them. vMenu does that for you, the same way GTA Online does.

There is no menu option for it. Fit the mines upgrade in the vehicle mods menu, sit in the driver seat and press the mine key.

## Which vehicles and which mine

The mine you get depends on the vehicle and on which mines upgrade is fitted.

| Vehicles | Mines |
| --- | --- |
| APC, Dune FAV, Half-track, Weaponized Tampa, Insurgent Pick-Up Custom, Technical Custom, TM-02 Khanjali, Speedo Custom, Mule Custom, Pounder Custom | Proximity mines, whichever upgrade is fitted. |
| Arena War vehicles: Issi, Scarab, Cerberus, Impaler, ZR380, Dominator, Imperator, Bruiser, Slamvan, Sasquatch and Brutus (all three Arena versions of each) | Kinetic, spike, EMP, slick or tar, in that order in the mods menu. |
| RC Bandito | Kinetic or EMP. |
| JB 700W | Spike or slick. |
| Champion, Buffalo STX, Deity, Jubilee, Granger 3600LX, Patriot Mil-Spec, Greenwood and Omnis e-GT | Slick mines. |

What each mine does:

| Mine | Effect |
| --- | --- |
| Proximity and kinetic | Explodes. |
| Spike | Pops tyres. |
| EMP | Shuts off the engine for a moment. |
| Slick | Makes the road slippery. |
| Tar | Slows vehicles down. |

## Keys

| Vehicles | Keyboard | Controller |
| --- | --- | --- |
| Arena War vehicles, RC Bandito, JB 700W | `Space` | D-pad right |
| All others | Horn, `E` | Horn, left stick press |

- **Tap, do not hold.** A mine drops when you let go of the key. Holding it for half a second or longer drops nothing.
- **The handbrake.** On a keyboard `Space` is also the handbrake, so a quick tap of the handbrake in an Arena War vehicle drops a mine. This is the same in GTA Online.
- **The horn.** In vehicles that use the horn key, the horn stays silent whenever a mine can be dropped. It honks as normal at all other times, for example while a menu is open or the vehicle is in the air.
- **Waiting.** You can drop a mine once every 0.75 seconds.
- **When it does nothing.** No mine drops while the vehicle is upside down or not on all its wheels, while a menu is open, or while you use no clip, freecam or prop placement.

## Permissions

| Permission | Allows |
| --- | --- |
| `vMenu.Enhanced.Menus.VehicleOptions.VehicleMines` | Dropping vehicle mines. No menu row. |

Without it, the mine key does what it normally does, so the horn honks again.
