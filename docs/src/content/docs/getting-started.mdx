## Installing vMenu Enhanced

vMenu Enhanced comes in two versions, one for each kind of FiveM server. Both have exactly the same menus and features, they only differ in the game they run on.

<CardGrid>
  <LinkCard
    title="On FiveM Enhanced"
    description="Your server runs GTA V Enhanced. Set it up in a few clicks with txAdmin, or install it by hand."
    href="/vmenu/enhanced/installing/fivem-enhanced/"
  />
  <LinkCard
    title="On FiveM Legacy"
    description="Your server runs the original GTA V, which is the regular FiveM most servers use. Set it up in a few clicks with txAdmin, or install it by hand."
    href="/vmenu/enhanced/installing/fivem-legacy/"
  />
</CardGrid>

Not sure which one you have? If your players start the game with **FiveM for GTA V Enhanced**, your server is FiveM Enhanced. Otherwise it is FiveM Legacy.

## Plugins

A plugin is a separate resource that adds its own menus inside vMenu. You never have to change vMenu itself for it.
